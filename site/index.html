Get Segurata
For your agent:
Read the prompt 
Help me audit this computer with Segurata, an open-source security CLI: https://github.com/segurata/segurata

1. Read https://raw.githubusercontent.com/segurata/segurata/main/.agents/skills/segurata-audit/SKILL.md and follow it.
2. If `segurata version` fails, install it with Go 1.26 or later: go install github.com/segurata/segurata/cmd/segurata@latest
   Other install options: https://github.com/segurata/segurata/blob/main/docs/releasing.md#installing
3. Run `segurata connectors` and tell me which connectors apply here. Ask me before running any that signs in to a provider or checks a credential over the network.
4. Start with the scan that needs no credentials:
   segurata doctor --connector browser-extensions
   segurata inventory browser-extensions
   segurata status
5. Summarize the findings by priority, with their IDs and next actions. Keep secret values and full inventory records out of the chat.
6. Do not apply any fix. For a fix, read https://raw.githubusercontent.com/segurata/segurata/main/.agents/skills/segurata-remediate/SKILL.md, show me the plan and wait for my approval.
